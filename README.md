# [素数大富豪＋](https://greenplus.github.io/qkplus/)

通常の素数大富豪、特殊ルール、定期大会を共通操作で遊べる対戦クライアントです。

- Classic: 5枚、7枚、11枚などの標準ルール
- Plus: 初期革命、四つ子素数、半素数
- 総当たり大会の参加登録、自動呼び出し、順位表示
- 対戦募集、グローバルチャット、観戦、切断復帰

ゲームサーバーは `greenplus/primeqk_online_server`、共通UIの作業用正本は親ワークスペースの `client-common/` と `qkplus-client-prototype/` にあります。
